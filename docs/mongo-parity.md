# mongo-tui: чек-лист паритета

Статус: аудит M6, 2026-11-14. Основание — ADR 0006. PostgreSQL-путь удалён.

Прогресс: M2a (2026-11-14) — адаптер `internal/mongo` и его живые тесты готовы
(CRUD, DDL, лимиты, read-only, транзакции, отмена, переключение базы). M2b
(2026-11-14) — TUI принимает `mongodb://`/`mongodb+srv://` и профили с
`engine = "mongo"`, спрашивает пароль в TUI, отправляет JSON-envelope в
workbench, различает null/missing в сетке, показывает полный документ во
вкладке OBJECT и переключает базу без сброса транзакции. M3 (2026-11-14) —
каталог MongoDB и дерево: Databases → Collections/Views → Indexes, Users и
Roles, карточка коллекции с полями по выборке, ключами индексов, статистикой,
options и validator; F5 и ленивая загрузка. M4 (2026-11-14) — гибридный
редактор: JSON-envelope остаётся каноном, ограниченный MQL компилируется в
тот же `query.Spec`; подсветка MQL/JSON, клиентская валидация перед отправкой,
автодополнение баз/коллекций/методов/полей/операторов/стадий и MQL-шаблоны.
M5 (2026-11-14): модуль, команда и бинарь переименованы в `mongo-tui`;
XDG-пути новые, старые `psql-tui` config/state копируются при первом запуске с
`.psql-tui.bak`, новые файлы не перезаписываются; README EN/RU и PRD
переписаны. M6 (2026-11-14): аудит паритета и удаление PostgreSQL-эталона.
Post-M6 hardening закрыт; остаются только внешние проверки x509/SRV/sharded.

В таблицах ниже OK означает, что поведение покрыто юнит- или живым тестом;
TODO — незакрытая внешняя проверка, SPIKE — историческое измерение.

PostgreSQL-пакеты удалены в M6: `internal/psql`, `internal/session`,
`internal/catalog`, `internal/sqlparse` и SQL-часть `internal/completion`.
Этот файл остаётся аудитом выполненной миграции.

Статусы:

- TODO — в mongo-tui ещё не сделано;
- SPIKE — поведение измерено в M0, в продукт не перенесено;
- OK — проверено живым тестом или ручным прогоном на docker-кластере;
- N/A — неприменимо к MongoDB, требование снято с объяснением.

## Условия выхода

Выполнено в M6:
1. PostgreSQL-пакеты удалены.
2. ADR 0001, 0002 и 0005 помечены superseded; README EN/RU и PRD переписаны
   под `mongo-tui`.
3. `psql-tui` config/state мигрированы; legacy-профили сохранены.
4. `go test ./...`, `make test-mongo` и CI зелёные; ручной прогон идёт от
   непривилегированного пользователя.

Post-M6 hardening закрыт: CON-02 (живой профиль), CON-04 (SCRAM/TLS/authSource; SRV
передаётся драйверу), CON-06/CON-07, CUR-03/CUR-04, ED-03/ED-04/ED-05/ED-08 и
CFG-01. CAN-04 — N/A: MongoDB разрешает kill своей операции без `killop`; ошибки
отмены показываются в UI. Остаются только внешние проверки x509/SRV/sharded.
